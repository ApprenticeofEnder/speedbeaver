# Installation

This guide goes over how to actually install the package itself. For more information on getting started with Speedbeaver, see our [quickstart guide](./quickstart.md) or the [configuration docs](./configuring.md).

## Pip

```bash
pip install speedbeaver
```

## UV

```bash
uv add speedbeaver
```

## Poetry

```bash
poetry add speedbeaver
```

## Other Package Managers

Please consult your package manager documentation for help with installing the `speedbeaver` package.

Or just look it up on StackOverflow, ask ChatGPT or Claude code, whatever people are doing to avoid reading documentation nowadays.
